# Main_Codex_openai_yago_test_01_08_06_2025

This repository demonstrates how to configure a free, fully local chatbot environment. The setup uses open source components including **Ollama**, **Docker**, **n8n**, **PostgreSQL**, and a lightweight **Evolution API** example. No paid services are required.

See [LOCAL_SETUP.md](LOCAL_SETUP.md) for step-by-step instructions, including a simple web interface using Gradio.
